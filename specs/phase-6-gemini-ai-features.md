# Phase 6 Specification: Gemini AI Features

## 1. Overview & Architecture
Integrate Google Gemini 2.5 Flash into Curia using the official `@google/genai` SDK strictly on the server side (`src/lib/gemini/client.ts`). The system provides three intelligent capabilities:
1. **Thread Summarizer**: Synthesizes long comment threads into TL;DR, key points, and debate perspectives.
2. **Toxicity & Spam Moderation Pre-Check**: Pre-publish screening for posts and comments with prompt injection defense, warning dialogs, and fail-open local fallbacks.
3. **Smart Community Matchmaker**: Contextual community recommendation for post drafts and Home page discovery.

---

## 2. Shared Infrastructure Spec

### 2.1 Server-Only Gemini Client (`src/lib/gemini/client.ts`)
- **Purpose**: Centralized, secure factory for the `@google/genai` SDK.
- **Inputs**: `GEMINI_API_KEY`, `GEMINI_MODEL` (default: `gemini-2.5-flash`).
- **Outputs**: Initialized `GoogleGenAI` instance or `null`.
- **Enforcement**: Server-only runtime. Never bundled or imported in client components.
- **Timeout**: 15-second AbortSignal on all LLM calls.

### 2.2 In-Memory Token Bucket Rate Limiter (`src/lib/gemini/rate-limiter.ts`)
- **Purpose**: Prevent quota exhaustion and abusive bursts.
- **Limits**:
  - Authenticated user: 20 calls per user ID per sliding hour.
  - Anonymous user: 10 calls per IP address per sliding hour.
- **Outputs**: `{ allowed: boolean, remaining: number, resetInSeconds: number }`.
- **Status Code**: Returns HTTP `429 Too Many Requests` with friendly retry-after JSON message.

### 2.3 Database Cache Migration (`supabase/migrations/00004_ai_features.sql`)
- **Table**: `public.ai_cache`
  - `id uuid PRIMARY KEY DEFAULT gen_random_uuid()`
  - `content_hash text UNIQUE NOT NULL`
  - `result jsonb NOT NULL`
  - `created_at timestamptz NOT NULL DEFAULT now()`
- **Columns Added**:
  - `moderation_verdict text DEFAULT 'allow'` on `public.posts`
  - `moderation_verdict text DEFAULT 'allow'` on `public.comments`
- **Cache Policy**: Summaries keyed by `hash(post_id + ":" + comment_count)`. Cache remains valid until a new comment is added.

## 3. Sub-Feature Specs

### Feature 1: Thread Summarizer (`/api/ai/summarize`)
- **Route**: `POST /api/ai/summarize`
- **Auth**: Allows authenticated users & anonymous reads (with IP rate limiting).
- **Inputs**: `post_id: string (uuid)`
- **Cache Check**: Queries `ai_cache` for `hash(post_id + ":" + post.comment_count)`.
- **Prompt & Token Budget**: Fetches post and top comments (capped at 60 comments, prioritized by score and depth variety).
  - System prompt: Neutral, objective, factual, zero username inclusion, no long quotes.
  - Response Schema:
    ```json
    {
      "summary": "2-3 sentence overview",
      "key_points": ["Point 1", "Point 2", "Point 3"],
      "disagreement": "Core tension or debate if present, else null"
    }
    ```
- **UI Component** (`src/components/post/thread-summary-card.tsx`):
  - Visible only when post has 8 or more comments.
  - Violet-glow accent styling (`#7C5CFF` border & glow).
  - Shimmer loading state, collapsible card, "Generated by AI" badge, and "Regenerate" button.

### Feature 2: Toxicity & Spam Moderation Pre-Check (`/api/ai/moderate`)
- **Route**: `POST /api/ai/moderate`
- **Auth**: Authenticated user required.
- **Inputs**: `text: string (1-10000 chars)`
- **Policy**:
  - `block`: Clear hate speech, severe harassment, violent threats, sexual content involving minors, malicious spam/phishing URLs.
  - `warn`: Borderline rude, hostile, or heated tone.
  - `allow`: Constructive discussions, strong opinions, technical criticism.
- **Prompt Injection Defense**: Text enclosed in `<USER_SUBMITTED_TEXT>` delimiters with explicit instructions to evaluate strictly as passive data.
- **Outputs**: `{ verdict: 'allow' | 'warn' | 'block', categories: string[], reason: string }`
- **Graceful Fallback**: If Gemini fails, times out, or quota is exceeded, fail open (`verdict: 'allow'`), applying heuristic local checks (blocked word regex + > 3 URLs triggers spam warning).
- **UI Flow**:
  - `block`: Inline danger alert with explanation, disables publishing.
  - `warn`: Confirmation modal ("This may come across as hostile. Post anyway?") with "Edit" and "Post anyway" buttons.
  - Verdict saved to `moderation_verdict` column on post/comment.

### Feature 3: Smart Community Matchmaker (`/api/ai/suggest-communities`)
- **Route**: `POST /api/ai/suggest-communities`
- **Auth**: Authenticated user required.
- **Inputs**:
  - For Create Post: `title: string`, `body?: string`, `available_communities: Community[]`
  - For Home Page: `joined_communities: string[]`, `recent_upvoted_titles: string[]`
- **Outputs**: Top 3 matched community names with a one-sentence rationale each. Validated strictly against registered communities.
- **UI Integration**:
  - `src/components/post/community-suggest-chips.tsx`: Debounced chips (minimum 20 chars) in `/submit`. Clicking a chip auto-selects the community.
  - `src/components/home/recommended-communities-card.tsx`: Rendered on Home page for users with < 3 joined communities, falling back to trending communities on failure.
